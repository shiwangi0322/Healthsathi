# 🩺 HealthSathi – AI-Powered Healthcare Assistant

HealthSathi is an AI-powered healthcare assistant that provides basic health guidance through voice, chat, and symptom-based interactions. It helps users access health information easily through a simple and user-friendly interface.

## ✨ Features

- 🎤 Voice Assistant with Speech-to-Text and Text-to-Speech
- 💬 AI Healthcare Chatbot
- 🩺 Symptom Checker
- 🌐 Hindi & English Language Support
- 🚨 Emergency Assistance
- 📜 Health Tips and Awareness
- 🔐 Secure Login & Signup
- 🕒 Conversation History

## 🛠️ Tech Stack

- Python
- Flask
- SQLite
- NLP (Natural Language Processing)
- Vosk Speech Recognition
- pyttsx3
- HTML, CSS, JavaScript

## 🚀 Installation

git clone https://github.com/shiwangi0322/Healthsathi.git
cd Healthsathi
pip install -r requirements.txt
python app.py
